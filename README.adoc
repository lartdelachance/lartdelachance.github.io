= Site

== Commande

Pour créer une nouveau `post` :
[source,bash]
--
hugo new --kind partie posts/2026/02/2026-02-26
--

Pour convertir les images :
[source,bash]
--
for f in $(find . -name '*.jpg');
  do echo "Converting $f";
  mogrify -format webP -quality 60 -define webp:lossless=false "$f";
  rm "$f";
done;
--
